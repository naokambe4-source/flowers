=== Can Eloksal Builder ===
Requires at least: 6.2
Requires PHP: 8.0
Stable tag: 1.0.0
License: GPLv2 or later

Can Eloksal temasının tüm bölümlerini blok editöründe sürükle-bırak bloklar olarak kullanmanızı sağlar.

== Gereksinim ==
Can Eloksal teması etkin olmalıdır.

== Kurulum ==
1. Eklentiler → Yeni ekle → Eklenti yükle → can-eloksal-builder.zip → Şimdi kur → Etkinleştir.
2. Can Eloksal → Sayfa Oluşturucu.

== Bloklar ("+" → Can Eloksal) ==
Hero Slider, Sayfa Başlığı (Hero), Güven Şeridi, Hizmetler, Görsel + Metin, Özellik Kartları (Bento),
Sektörler, Proses / Zaman Çizelgesi, Galeri, Tam Genişlik CTA, CTA Bandı, Blog Yazıları, Referans Logoları,
İletişim Kartları, Harita, İletişim Formu, Teklif Formu, Banka Hesapları, Bölüm Başlığı,
Bölüm (Kapsayıcı — içine her türlü WordPress bloğu).

Her bloğun ayarları sağ paneldedir; önizleme anında güncellenir. Boş bırakılan alanlar
Can Eloksal → Tema Ayarları'ndaki değerleri kullanır.

== Araçlar ==
* Ana sayfayı düzenlenebilir bloklara aktar (önceki içerik yedeklenir, geri dönülebilir).
* Hazır düzenden yeni sayfa: Kurumsal açılış, Hizmet tanıtım, İletişim, Duyuru/Kampanya, Boş.
* Desenler: editörde "+" → Desenler → Can Eloksal.
